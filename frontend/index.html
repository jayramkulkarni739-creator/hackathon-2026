💡 NovaSphere FAQ

Are these workshops and events completely free?

Yes! Every workshop, 3D lab, and hackathon organized under NovaSphere is 100% free for students worldwide.

Do I need prior coding or 3D graphics experience?

Not at all. We offer dedicated tracks ranging from foundational web development to cutting-edge AI and spatial computing.

How does the frontend connect to the backend?

The plain JavaScript frontend uses the native fetch() API to call FastAPI endpoints (/api/events and /api/register). CORS is enabled on the backend to allow cross-origin communication.
